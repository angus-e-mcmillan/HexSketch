# The tests' own questions

Six drawings the tests read, so changing the paper never breaks them: a
reaction with a hazard, a retrosynthesis with an alternative answer, and the
four shapes of analysis answer (a highlighted atom, a ranking, a written word,
a written number).

They were the paper's own questions once. Nothing but the tests reads them, so
they may say anything, and the chemistry in them need not be worth asking.
